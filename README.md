# tasknode-dev-task

## Conventions

- One directory per task, named after the thing being implemented (e.g. `lru-cache/`, `union-find/`).
- Each directory contains the implementation file(s) and a matching test file.
- Commit messages reference the Task Node task title so the history stays traceable back to the platform.
